======================================

COPIED, UNCHANGED, FROM PEOPLE (folder lib/)

Each file is the published release, byte for byte. All four were published before GitHub Copilot's
first preview (29 June 2021), which is why these versions were chosen. The SHA-256 lets anyone compare
a file here with the one at its source.

What this shows and what it cannot: a release date before Copilot, a named author and an unchanged
file are good evidence that people wrote the code. Simpler code-completion tools existed earlier, and
nobody can prove how any code was typed.

NOT COPIED: WRITTEN BY AN AI ASSISTANT

- index.html: the page's structure and its words. It has no style sheet of its own; it only uses
  Bootstrap's class names, so which Bootstrap parts go where was still chosen by the assistant.
- app.js, all of it: the gift list, how a card is put together, the filter, budget and sort, the
  "I bought this" button and its shared list, the loading of the tracked prices, and the lines that
  switch the libraries above on (their settings, the confetti colors).
- tools/prices.mjs and .github/workflows/prices.yml: the hourly price tracker.

These parts are specific to this list.
